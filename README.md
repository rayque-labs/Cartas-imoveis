# Cartas Imóveis

Site estático responsivo de apresentação e captação de contatos para cartas de crédito imobiliário.

## Arquivos
- `index.html`: página principal
- `style.css`: estilos
- `app.js`: formulário que abre mensagem no WhatsApp
- `config.js`: configurações de contato
- `privacidade.html`: política de privacidade
- `vercel.json`: configuração de deploy

## Publicação
Conecte este repositório à Vercel. Framework: Other. Build command: vazio. Output directory: vazio.

## Atenção
Verifique dados de contato, documentação e requisitos legais e de publicidade antes de anunciar. O formulário não armazena leads automaticamente.
